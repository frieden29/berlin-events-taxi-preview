خصوصية المعاينة المستقلة

هذه المعاينة لا تستخدم GoatCounter أو Cloudflare Web Analytics أو Online Now، ولا تفتح اتصال حضور ولا تسجل زيارات لدى هذه الخدمات. لا تسجيل دخول ولا حسابات.

الوضع واللغة والمفضلة تحفظ محليًا في المتصفح. تبقى المفاتيح الحالية، وقد تُشارك التفضيلات مع مواقع أخرى على أصل frieden29.github.io نفسه. حذف بيانات المتصفح قد يزيلها.

الموقع الجغرافي اختياري بعد إجراء منك وإذن المتصفح، لحساب المسافات محليًا؛ لا يرسل إلى خادم التطبيق. قد يستخدم المتصفح مزود خدمة لتحديد الموقع. البحث والمرشحات والمفضلة لا ترسل لخدمة إحصائيات. لا تعني هذه المعاينة عدم وجود اتصالات شبكية: تستضيف GitHub Pages الملفات، وتُحمّل مربعات الخرائط من OpenStreetMap والخطوط الاحتياطية من Google Fonts عند الحاجة؛ تتلقى تلك الجهات بيانات الاتصال التقنية مثل عنوان IP. عند اختيار الملاحة أو رابط مصدر، تتصل بخدمة خارجية وقد يرسل إليها موقع الوجهة.

البيانات لقطة ثابتة وليست طلبات ركوب أو حركة مرور حية. انتهاء أكتوبر قيد واجهة حسب ساعة الجهاز.

ترجمة لتسهيل القراءة تحتاج مراجعة قانونية متخصصة.

Datenschutz der separaten Vorschau

Diese Vorschau verwendet weder GoatCounter noch Cloudflare Web Analytics oder Online Now. Sie öffnet keine Anwesenheitsverbindung und sendet keine Besuche an diese Dienste. Keine Anmeldung oder Konten.

Modus, Sprache und Favoriten bleiben im lokalen Browserspeicher. Bestehende Schlüssel bleiben erhalten; andere Seiten unter demselben Ursprung frieden29.github.io können diese Einstellungen teilen. Das Löschen von Browserdaten kann sie entfernen.

Der Standort wird nur nach Ihrer Aktion und Browserfreigabe für lokale Entfernungsberechnungen verwendet, nicht an einen App-Server übertragen. Der Browser kann hierfür einen Standortdienst verwenden. Suchtexte, Filter und Favoriten werden nicht an Analytics gesendet. Netzwerkzugriffe bleiben: GitHub Pages liefert Dateien, OpenStreetMap Kartenkacheln und Google Fonts bei Bedarf Ersatzschriftarten. Dabei erhalten Anbieter technische Verbindungsdaten wie die IP-Adresse. Navigation oder Quellenlinks öffnen externe Dienste; das Navigationsziel wird dabei übermittelt.

Statische Quelldaten, keine Live-Nachfrage. Der Oktober-Ablauf ist eine Oberflächenbeschränkung nach Gerätezeit. Dieser Hinweis ersetzt keine rechtliche Prüfung.

Separate preview privacy

No GoatCounter, Cloudflare Web Analytics or Online Now runs here. No presence connection, analytics visits, sign-in or accounts.

Mode, language and favorites stay in browser storage using existing keys, potentially shared with other pages on frieden29.github.io. Clearing browser data can remove them. Location is optional after your action and browser permission, used locally for distances, not sent to an app server. The browser may use a location provider. Search, filters and favorites are not sent to analytics.

GitHub Pages serves files, OpenStreetMap serves map tiles and Google Fonts may supply fallback fonts. These providers receive technical connection data such as IP addresses. Navigation and source links contact external services; navigation sends the destination. Source snapshots are not live demand. October expiry is based on device time. Ayrı önizleme gizliliği

GoatCounter, Cloudflare Web Analytics ve Online Now çalışmaz. Çevrimiçi durum bağlantısı, analiz ziyareti, giriş veya hesap yoktur.

Mod, dil ve favoriler mevcut anahtarlarla tarayıcıda saklanır; aynı frieden29.github.io kökenindeki sayfalar bunları paylaşabilir. Tarayıcı verilerini silmek bunları kaldırabilir. Konum, kullanıcı eylemi ve tarayıcı izniyle yerel mesafe hesabı içindir, uygulama sunucusuna gönderilmez. Tarayıcı konum sağlayıcısı kullanabilir. Arama, filtreler ve favoriler analize gönderilmez.

GitHub Pages dosyaları, OpenStreetMap harita döşemelerini ve gerektiğinde Google Fonts yedek yazı tiplerini sağlar. Sağlayıcılar IP adresi gibi teknik bağlantı verilerini alır. Navigasyon ve kaynak bağlantıları dış hizmetleri açar; navigasyon hedefi iletilir. Veriler sabit anlık görüntüdür, canlı talep değildir. Ekim süresi cihaz saatine bağlıdır. Çeviri uzman hukuki inceleme beklemektedir.
